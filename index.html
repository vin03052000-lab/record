設定 Supabase 連線

BetTrack 使用 Supabase 儲存資料，讓你在任何裝置都能同步紀錄。只需幾步即可完成設定。

1
前往 supabase.com 建立免費帳號，然後新增一個 Project。
2
進入 Project → SQL Editor，貼入並執行以下指令建立資料表（點右側按鈕複製）： 
CREATE TABLE bets (
  id          uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  account     text NOT NULL,
  date        text NOT NULL,
  time_str    text,
  ticket      text,
  type        text,
  league      text,
  match_name  text,
  bet_team    text,
  odds        numeric,
  amount      numeric DEFAULT 0,
  valid       numeric DEFAULT 0,
  profit      numeric DEFAULT 0,
  result      text,
  created_at  timestamptz DEFAULT now()
);
ALTER TABLE bets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow all" ON bets FOR ALL USING (true);
3
到 Project → Settings → API，複製以下兩項填入：
Project URL
Anon public key
